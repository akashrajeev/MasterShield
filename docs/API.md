# MasterShield API Contract

Base URL for local development:

```text
http://localhost:8000
```

Interactive OpenAPI documentation is available at `/docs` when the FastAPI service is running.

## Health

### `GET /health`

Returns service status and API version.

Example response:

```json
{
  "status": "ok",
  "service": "mastershield",
  "version": "1.0.0"
}
```

## Attack intelligence

### `GET /api/catalog/summary`

Returns catalog counts, family distribution, rail coverage, critical/high-difficulty counts, average novelty and generator information.

### `GET /api/catalog/discover?limit=20`

Returns safe, non-operational composite threat hypotheses for defensive research.

### `GET /api/attacks`

Returns the canonical attack catalog.

### `GET /api/attacks/{attack_id}`

Returns one canonical attack definition.

## Simulation

### `POST /api/simulate`

Request body:

```json
{
  "events": 1000,
  "seed": 829134,
  "attack_ids": ["ID-01", "TE-01"],
  "fraud_rate": 0.12,
  "difficulty": "high",
  "adaptation": "static",
  "noise": "medium",
  "threshold": 0.5
}
```

The attack list can be omitted to sample across the complete catalog. `attack_ids` must use IDs from the canonical `data/attacks/attacks.json` catalog.

The response contains a stable simulation ID, event count, fraud-event count, selected attack count, graph summary and a sample of generated synthetic records.

### `GET /api/simulations/{simulation_id}`

Returns persisted simulation metadata.

### `GET /api/simulations/{simulation_id}/events?limit=100&offset=0`

Returns a paginated deterministic view of generated synthetic events.

### `GET /api/simulations/{simulation_id}/results`

Returns simulation metadata, latest experiment metrics and closed-loop rounds.

## Detection

### `POST /api/detect`

Runs the full training/test evaluation pipeline for the supplied simulation configuration. It returns overall metrics, threshold sweep results, grouped results, latency and sample predictions.

### `POST /api/predict`

Runs model-backed point predictions over supplied synthetic events. Optional internal identity fields are filled when omitted.

## Investigation

### `GET /api/transactions/{transaction_id}`

Returns the deterministic synthetic transaction corresponding to the configured seed/event population.

### `GET /api/transactions/{transaction_id}/assessment`

Returns model-backed risk score, decision, prediction, attack metadata and top detection signals.

## Adversarial loop

### `POST /api/adversarial/search`

Runs bounded synthetic hard-variant search against the detector.

### `POST /api/adversarial/harden`

Runs multi-round hardening with separate training, red-team and untouched test populations. Each round is returned as `{ "round": ..., "metrics": {...}, ... }`.

## Experiment IDs

Simulation and experiment IDs incorporate the seed/configuration so frontend requests can reference a deterministic research run.

## Data contract principles

- All values are synthetic.
- Attack ground truth is generated by the simulator, not inferred from the detector.
- Ground-truth and attack metadata are excluded from model features.
- Detector outputs are probabilities/scores plus decisions, not authoritative payment actions.
- Errors are returned as HTTP errors with a JSON `detail` field.
- The API converts non-finite NumPy/pandas values into JSON `null` rather than emitting invalid JSON.
